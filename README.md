# GlowShop Homepage

- **Library Chosen:** Mantine (mantine.dev)
- **Installation:** `npm install @mantine/core @mantine/hooks`
- **Components Built:** Header (Navbar), Hero, Features, ProductCard, and Footer under `src/components/`.
- **Time Saved:** Mantine provided pre-styled layout containers, grid systems, and components, allowing me to focus entirely on component modularity and aesthetic UI design.
